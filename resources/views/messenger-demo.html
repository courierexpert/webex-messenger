Webex Messenger Demo

This page demonstrates the Webex Messenger widget. The messenger should appear as a floating button in the bottom-right corner.

Features

  • Real-time messaging with WebSocket support
  • Minimizable widget interface
  • Mobile responsive design
  • Conversation list with search
  • Message status indicators (queued, delivered, failed)
  • Unread message badges
  • Auto-scroll to latest messages
  • Pagination for message history

Integration Instructions

To integrate the messenger widget into your application, see the example code below. 

<!-- Add to your HTML -->
<div id="messenger-app"></div>

<!-- Include scripts -->
<script src="/build/assets/app.js" type="module"></script>

<script type="module">
  import { MessengerWidget } from '/build/assets/app.js';
  import Vue from 'vue';

  new Vue({
    el: '#messenger-app',
    components: { MessengerWidget },
    template: `
      <MessengerWidget
        :token="authToken"
        :pusher-config="pusherConfig"
        :minimized="true"
        @toggle="handleToggle"
      />
    `,
    data() {
      return {
        authToken: 'your-bearer-token-here',
        pusherConfig: {
          key: 'your-pusher-key',
          cluster: 'eu'
        }
      };
    },
    methods: {
      handleToggle(isMinimized) {
        console.log('Widget toggled:', isMinimized);
      }
    }
  });
</script>
